# 布列紧街拍评分大师

Creator：[胶着状态 In A Film State（小红书）](https://xhslink.cn/m/ArZr9m8zJZ1) · [@j1mmywoo（Instagram）](https://www.instagram.com/j1mmywoo/)

一个给街头摄影作品打分和提供简洁点评的 Codex Skill。“布列紧”是对“布列松”的中文谐音梗；英文名 Bress-On 则有“继续按下快门”的双关感。

## 打分流程

每张照片按照六个维度评估：

| 维度 | 分值 | 判断依据 |
|---|---:|---|
| 瞬间与人的意味 | 25 | 时机、动作、表情、互动、情绪和叙事价值 |
| 构图与画面组织 | 20 | 主体位置、平衡、边缘、视觉层级和空间使用 |
| 层次与环境关系 | 15 | 前中后景、人物关系、主体与环境的联系 |
| 光线、影调与色彩 | 15 | 光线质量、明暗分离、色彩关系和气氛 |
| 独创性与作者表达 | 15 | 个人视角、意外性、含蓄感以及是否落入俗套 |
| 技术完成度 | 10 | 对焦、曝光、动态表现和后期是否服务于照片 |

评测时先判断照片真正的主体和瞬间，再检查整张画面及边缘，分别完成六项评分，扣除技术失误、背景干扰、重叠、空洞、摆拍感或陈词滥调造成的损失，最后给出一个优点、一个主要问题和一个可执行的改进建议。

分数参考：90–100 杰出；85–89 很强；80–84 良好；70–79 合格；60–69 较弱；60 以下建议淘汰。

## 安装到 Codex

```bash
git clone https://github.com/J1mmyWoo/bress-on-street-photo-scoring-master.git ~/.codex/skills/bress-on-street-photo-scoring-master
```

重启 Codex，上传照片后直接说：`用布列紧街拍评分大师给这些照片打分。`

## 使用声明

本工具仅用于个人选片、打分和参考，不适用于严肃的艺术评审、专业赛事评委工作或商业评价。所有分数都是主观意见，不代表作品艺术价值的客观结论。本项目与 Henri Cartier-Bresson、Magnum Photos、Leica 或 LFI 没有隶属或合作关系。
